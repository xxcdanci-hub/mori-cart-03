# Third-party inspiration

The MORI Cart interaction was informed by these MIT-licensed public projects:

- [14islands/r3f-scroll-rig](https://github.com/14islands/r3f-scroll-rig), copyright 2023 14 Islands AB — reference for synchronizing a single sticky React Three Fiber canvas with DOM scroll sections.
- [ddVital/IPhone-3d-lading-page](https://github.com/ddVital/IPhone-3d-lading-page), copyright 2024 David Vital — reference for chapter-based product storytelling and focused product views.

No Apple media, trademarks, 3D assets, or source files were copied into this project. The implementation is original and uses the MORI cart's existing visual system.
